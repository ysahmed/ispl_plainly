Statistical learning, in plain language

The whole of ISLP — chapter by chapter, section by section — written for a reader who does not enjoy math notation. The formulas stay, but every one of them is read out as a sentence you can actually follow, and every idea that can be shown on a chart is shown on a chart you can poke at.

How this site works

Each page takes one section of the book. The section numbers are kept, so you can read alongside a paper copy — but nothing on this site assumes you can read a formula unaided.

Every formula comes with its English translation

You will never meet a formula on its own. First the idea in words, then the formula, then the formula again as one sentence: "the ridge penalty makes large coefficients expensive." If you can say what a formula does in one sentence, you have understood it — that is the bar this site aims for.

Charts are there to be played with

Sliders, buttons and hover readouts are part of the explanation, not decoration. When a chart says "drag this", drag it: the numbers are usually the argument.

Nothing is derived

Proofs and long derivations are skipped on purpose. Where the book does something algebraic, this site says what it means and moves on. The exception is Notation in Chapter 1 — one page that decodes the symbols once, so every later page can use them without ceremony.

Running the site

It is a folder of plain HTML — open index.html directly, or serve it so everything (charts, formulas, data) behaves exactly as it will online:

cd /home/waesh/Learning/ISLP
python3 serve.py          # then open http://localhost:8000

The lab walkthroughs that come with later chapters need the book's Python package. Set this up once, before Chapter 2's lab:

python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install ISLP pandas matplotlib scikit-learn statsmodels jupyterlab

The charts on this site run entirely in the browser — they need no Python at all.

Source: James, Witten, Hastie, Tibshirani, Taylor — An Introduction to Statistical Learning, with Applications in Python (ISLP, Springer 2023). This site is a study companion: explanations are re-written in plain language, formulas are quoted for teaching purposes, and every chart is drawn from the book's own datasets.
