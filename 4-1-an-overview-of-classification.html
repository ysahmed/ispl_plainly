An overview of classification

Chapter 3 predicted numbers. This chapter predicts categories: defaulted or not, fraud or not, which of three illnesses. The shape of the problem changes very little — but the answer is now a label, and almost every method handles it the same two-step way: estimate probabilities, then pick the biggest.

Reading

  • Read The Chapter 4 introduction and section 4.1 (p. 135). It is short — two pages of framing and one picture of the data the whole chapter runs on.
  • Skim Nothing yet. The method list in the introduction (logistic regression, LDA, QDA, naive Bayes, KNN) is a table of contents, not something to memorise now.
  • Then Section 4.2 answers a question you may not have thought to ask: can't we just run linear regression on the categories? The answer explains why this whole chapter exists.

Key ideas

A qualitative response — eye colour, fraud yes/no, a diagnosis — makes the problem classification: assigning an observation to a class. Most methods do it in two steps: first estimate the probability that the observation belongs to each class, then assign it to the class with the highest probability. That second step is a threshold, and where you set it decides which kinds of mistakes you make. Classifiers are judged on data they never trained on, exactly like regression models.

What you will know afterwards

  • classification vs regression
  • qualitative = categorical response
  • class, classifier, classification
  • probabilities first, labels second
  • train/test split applies to classifiers too
  • the Default data set

1. What a classification problem looks like

The chapter opens with three examples, and they are worth reading slowly because between them they cover the whole species:

SituationThe classesThe predictors
Emergency room stroke, drug overdose, epileptic seizure the patient's symptoms
Online banking fraudulent transaction, legitimate transaction IP address, past transaction history, and so on
DNA analysis mutation is disease-causing, mutation is harmless sequence data from patients with and without the disease

Three things carry over from regression unchanged. You still get a set of training observations (x1, y1), …, (xn, yn) and build a classifier from them. You still care about observations the classifier has never seen — a rule that memorises the training rows is worthless in the emergency room. And yi is still the answer column; it just contains words instead of numbers.

Two steps, almost always

The book points out that many classifiers first predict the probability that the observation belongs to each class, and only then assign the class with the highest probability. Keep that shape in mind: it is why a method called "logistic regression" belongs in a classification chapter, why thresholds matter, and why a classifier can be wrong in interesting ways — you can have a confident label from a 51/49 probability and treat it exactly like a 99/1 one.

2. The chapter's test subject: the Default data

Every example from here to the exercises runs on one simulated data set, so meet it now. The Default data describes 10,000 credit-card holders. The response Y is whether they defaulted on their payment that month (Yes/No — a qualitative response, so this is classification, not regression). The predictors are annual income and monthly credit card balance.

Two facts about it set up everything that follows: only about 3.3% defaulted (333 people out of 10,000 — a rare class), and defaulters tend to carry much higher balances. You can see both at once — then try the simplest classifier there is, a single vertical line:

The book's own warning about this data

Section 4.1 flags that Figure 4.1 shows a very pronounced relationship between balance and default, and that most real problems are far messier — the link is deliberately exaggerated here so the classification methods are easy to see working. When your own data looks less clean than this, that is normal, not failure.

Also note what the book says about Figure 4.1 itself: because defaulters are so rare, the book plots only a fraction of the non-defaulters in its scatterplot so the orange dots stay visible. The demo above draws all 9,667 of them, which is why the blue mass looks so much denser than the book's picture.

3. The road ahead

Section 4.1 is only a signpost; the methods arrive next. The chapter's order, and where each piece lives on this site:

  • 4.2 — why you cannot dodge the topic by running Chapter 3's linear regression on 0/1 labels.
  • 4.3 — logistic regression: model the probability of a class directly, with a curve that can never leave [0, 1].
  • 4.4 — the generative family: LDA, QDA and naive Bayes, which model the predictors inside each class and flip the question around with Bayes' theorem.
  • 4.5 — putting them in a ring together: no method wins everywhere, so how do you choose?
