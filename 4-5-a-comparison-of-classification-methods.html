A comparison of classification methods

Which classifier should you use? The honest answer, which the book spends two pages proving from both directions, is it depends on the shape of the truth and how much data you have. First the paper argument (the methods nest inside each other), then the experimental one (six simulated worlds, six methods, no universal winner).

Reading

  • Read Section 4.5 in full (pp. 161–166). In 4.5.1 read the four bullet observations carefully — they are the section's payload. In 4.5.2 read each scenario's verdict; the boxplots themselves just show spread.
  • Skim Equations 4.32–4.34 — recognise them as "linear, quadratic, sum-of-pieces" and move on.
  • Then Section 4.6 changes the subject to responses that are neither categories nor plain numbers — counts like bike rentals.

Key ideas

Written as formulas, LDA, QDA and naive Bayes are nested restrictions of each other: LDA is QDA with shared covariance; surprisingly, LDA is also a special case of naive Bayes; Gaussian naive Bayes is LDA with diagonal covariance; QDA and naive Bayes each have forms the other cannot express (QDA has interactions, naive Bayes can be arbitrarily wiggly per feature). Logistic regression has the same linear log-odds form as LDA but estimates it without assuming normality. In practice the six book scenarios show the pattern: linear truth → LDA or logistic; moderately bent truth → QDA or naive Bayes; complex truth → KNN, if K is chosen well and n is large.

1. On paper: the methods nest inside each other (4.5.1)

Set up the comparison so every method answers the same question: with K classes, pick a baseline class K and assign observations to the class maximising

$$\log\left(\frac{\Pr(Y = k \mid X = x)}{\Pr(Y = K \mid X = x)}\right)$$

— the log-odds against the baseline. Now write that quantity for each method and look only at its shape in x:

  • LDA (4.32): a linear function of x — a straight-line score, with coefficients built from estimates of π, μ and Σ under the normal assumption.
  • QDA (4.33): quadratic — linear terms plus xjxl cross-products, because each class has its own Σ.
  • Naive Bayes (4.34): a constant plus a sum of separate functions of each feature, ak + Σj gkj(xj) — each feature gets its own curve, and the curves are added, never multiplied. (The book notes this is a "generalized additive model", a Chapter 7 topic.)

Comparing the three shapes yields the section's four observations:

  1. LDA is a special case of QDA — set all the class covariances equal and QDA's formula becomes LDA's. (No surprise; that is literally the assumption difference.)
  2. LDA is a special case of naive Bayes too. Any classifier with a straight-line boundary is naive Bayes with linear gkj functions — and the book flags how counterintuitive this is: LDA assumes normality with a shared covariance, naive Bayes assumes independence. Wildly different stories, same algebra.
  3. Gaussian naive Bayes is a special case of LDA — model each feature within class as univariate normal and you have LDA with a diagonal (no-correlation) covariance. So the containment runs both ways between those two.
  4. QDA and naive Bayes contain neither each other. Naive Bayes is restricted to be purely additive — feature functions are summed, so it can never express interactions ("high balance and student and rain"). QDA's cross-product terms are exactly interactions, so QDA wins when interactions matter; naive Bayes can instead bend each feature arbitrarily, which QDA's single quadratic cannot.

Conclusion: "none of these methods uniformly dominates the others" — the winner depends on how the predictors really distribute within each class, plus n and p (the bias–variance trade-off wearing a new hat).

Where does logistic regression fit?

Recall 4.3.5's multinomial form: its log-odds against the baseline are linear in the predictors — identical in shape to LDA's (4.32). The only difference is where the numbers come from: LDA's coefficients are functions of Gaussian estimates (means, covariances, priors); logistic's come from maximising the likelihood without assuming any distribution for X. Therefore:

  • if the normality assumption is roughly true, expect LDA to win (it used a true assumption for free);
  • if it is badly false, expect logistic to win (it assumed nothing).

KNN's four conditions

KNN from Section 2.2.3 reappears as the wildcard: no assumptions at all about boundary shape, just neighbourhood votes. The book's bullets:

  • KNN should dominate LDA and logistic when the true boundary is highly non-linear — provided n is very large and p is small.
  • KNN needs n much larger than p, because it is non-parametric: low bias, high variance, and variance is bought off with data.
  • Boundary non-linear but data only modest (or p not small)? QDA may be preferred — it bends while using its parametric assumption to keep the sample requirement low.
  • Unlike logistic regression, KNN tells you nothing about which predictors matter — no coefficient table, no interpretation.

2. In practice: six scenarios, six methods, one race (4.5.2)

Now the experiment. The book generates data from six different worlds (p = 2 predictors each; three with a straight Bayes boundary, three bent), draws 100 separate training sets per world, fits every method to each, and records test error on a large test set — boxplots of the 100 results appear in Figures 4.11 (linear worlds) and 4.12 (non-linear). The methods: logistic regression, LDA, QDA, naive Bayes (Gaussian features), and KNN twice — K = 1, and K chosen automatically by cross-validation (the Chapter 5 technique).

The pattern the book wants you to internalise:

The selection rule, in three lines

Boundary actually straight → LDA or logistic regression (pick logistic when normality is doubtful). Boundary moderately bent → QDA or naive Bayes (QDA if n supports the extra parameters, naive Bayes if n is tight). Boundary seriously complicated → KNN or another non-parametric method, but only with enough data and a well-chosen smoothness — Chapter 5 is exactly about choosing it. And no matter what: transformations (X², X³ terms in logistic; cross-products in LDA) let you slide between the extremes, which is the bias–variance dial again.

That last point closes the section: adding all quadratic and cross-product terms to LDA gives a model with QDA's form (different estimates, same shape), so "LDA versus QDA" is not a binary choice but a slider — how much curvature are you willing to pay for, with the data you have?
